# 定价机制分析方法

## 核心问题

谁付钱、为什么付、按什么单位付、交付一次要花多少钱、续费依据是什么。

## 分析表

| 项目 | 必答内容 |
|---|---|
| 付费方 | 决策人、预算来源、使用者是否同一人 |
| 计价单位 | 账号/项目/设备/点位/容量/模块/调用量 |
| 收入类型 | 一次性软件、订阅、硬件、实施、运维、增值服务 |
| 价格锚点 | 与人工成本、风险损失、竞品价格或硬件价值的关系 |
| 交付成本 | 售前、实施、定制、算力、存储、运维、渠道分成 |
| 毛利 | 收入－直接交付成本；口径必须明确 |
| 续费依据 | 持续数据、持续服务、持续模型/规则更新 |
| 回本周期 | 初始投入÷月度净收益 |

## 决策

- ✅可规模化：计价单位清晰、交付成本可控、续费价值持续。
- ⚠️项目制：收入成立但高度依赖定制和人力。
- ❌伪商业模式：只算售价，不算交付、运维和获客成本。

## 明确不做

不使用“市场很大”“客户愿意付费”等无证据结论；没有真实报价时写区间和假设。
