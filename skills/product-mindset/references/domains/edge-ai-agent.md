# Edge AI + Agent AI产品分析

## 何时加载

涉及摄像机、边缘网关、平板终端、安防IoT、本地模型、云边协同、Agent工具调用或离线运行。

## 云边端职责

| 层级 | 适合职责 | 不应承担 |
|---|---|---|
| 设备端 | 采集、轻量推理、即时控制、断网可用 | 大规模跨设备知识与复杂编排 |
| 边缘端 | 多设备接入、本地聚合、隐私数据处理、低时延Agent | 无限制模型常驻和全量长期存储 |
| 云端 | 训练、策略管理、跨域分析、模型/知识更新 | 替代所有本地实时控制 |

## Agent产品门禁

1. Agent目标是否可验证，不是泛化“更智能”。
2. 可调用哪些工具；每个工具的读取、写入、删除、控制权限。
3. 哪些动作必须人工确认，哪些可自动执行。
4. 错误执行如何撤回、补偿和审计。
5. 模型不确定时如何展示置信度、拒答或转人工。
6. 断网、模型不可用、传感器异常时如何降级。
7. 数据是否出域，敏感视频/人脸/身份数据如何处理。

## 成本与性能

| 指标 | 要求 |
|---|---|
| 端到端延迟 | 按场景给P50/P95，不写“实时” |
| 单次推理成本 | 云API、GPU、电耗、人力复核全部计算 |
| 内存/显存 | 峰值、常驻、并发模型数 |
| 离线可用 | 可持续时长、数据补传、策略缓存 |
| 准确性 | 误报、漏报、置信度、人工复核率 |

## PoC成功标准

必须使用真实设备、真实数据量、真实网络条件和真实操作人员。代码模拟通过不算产品PoC通过。

输出至少包含：目标场景、基线、设备数量、数据规模、成功指标、失败止损线、人工接管方案、TCO。
